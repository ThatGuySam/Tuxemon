# Interface Demo

These are actual frames from the compiled ROM, driven through PyBoy buttons. The order follows the current research judgment, not a measured usability ranking. Walk and try every mode in the running Mac game. The first eight also work with authored behavior in native USB playback. Paired text requires the owned Mac bridge.
